resolvent4py

Developers: Alberto Padovan (NJIT), Vishal Anantharaman (Caltech), Clancy Rowley (Princeton)

Resolvent4py is a parallel Python package shipping with state-of-the-art algorithms for the analyis, control, and model reduction of large-scale linear systems. Distributed-memory parallelism is enabled through mpi4py, petsc4py and slepc4py.
